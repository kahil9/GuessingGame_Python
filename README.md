# Overview
This project is a Python-based number guessing game that challenges players to guess a randomly generated number between 1 and 100 within five attempts. The game includes user interaction, input validation, randomized gameplay, and a themed ASCII game-over screen.

# Objective
The objective of this project was to practice fundamental Python programming concepts, including:

- User input handling
- Conditional logic
- Loops
- Exception handling
- Random number generation
- Basic terminal formatting

#Features
- Random number generation between 1 and 100
- Five-attempt guessing system
- Input validation for non-numeric entries
- Dynamic attempt counter
- Win and lose conditions
- ASCII art game-over screen
